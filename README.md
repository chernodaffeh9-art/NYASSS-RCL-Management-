# NYASSS-RCL Management

Management system for the New Yundum Academic Senior Secondary School Red Cross Link (NYASSS-RCL).

## Planned Features

- Member registration
- Credential management
- QR-code verification
- Secure credential lookup
- Member records
- Administrative dashboard
- Card issuance and management
